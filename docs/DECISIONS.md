# 기술·콘텐츠 결정 기록

중요한 결정을 날짜순으로 기록합니다. 이미 확정된 결정을 다른 AI 도구가 반복해서 뒤집지 않도록 하는 문서입니다.

## 작성 형식

```markdown
## YYYY-MM-DD — 결정 제목

- 상태: 제안 / 승인 / 폐기 / 대체
- 결정:
- 이유:
- 검토한 대안:
- 영향 범위:
- 되돌리는 방법:
- 관련 Issue/PR:
```

## 2026-08-03 — GitHub를 코드의 단일 진실 공급원으로 사용

- 결정: 부부한의원 홈페이지의 최신 소스코드는 기존 GitHub 저장소 `main`을 기준으로 한다.
- 이유: 여러 컴퓨터와 AI 도구에서 일관된 최신 상태를 이어받기 위함이다.
- 검토한 대안: 프로그램별 복사본, 별도 관리 저장소
- 영향 범위: 모든 개발·SEO 수정 작업
- 되돌리는 방법: 없음. 운영 원칙 변경 시 새 결정 기록 작성
- 관련 Issue/PR: OPS-001
