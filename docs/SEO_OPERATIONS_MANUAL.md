## [OPS-101] 월간 Search Console & 서치어드바이저 점검

검색 포털(Google, 네이버)의 크롤러가 웹사이트를 문제없이 수집하고 색인을 생성하는지 확인하는 필수 정기 업무입니다.

### 1. Google Search Console 점검 항목 (매월 1회)
* **목적**: 구글 내 수집 에러 조기 식별 및 핵심 키워드 유입 모니터링
* **체크리스트**:
  1. **[색인 생성 범위] 오류 확인**: '실패함(Error)' 또는 '경고(Warning)' 상태의 URL이 있는지 확인합니다. (예: 404 Not Found, 리디렉션 에러, 캐노니컬 불일치)
  2. **[Sitemaps] 제출 현황 확인**: `https://booboo.co.kr/sitemap.xml` 상태가 **'성공(Success)'**인지 재차 검증합니다.
  3. **[실적(Performance)] 쿼리 분석**: 최근 28일 기준 유입 클릭수가 많은 상위 키워드(예: `목포 부부한의원`, `목포 교통사고 한의원`, `목포 추나요법`)의 평균 게재순위 및 노출수 추이를 추적합니다.
  4. **[보안 및 수동 조치]**: 사이트 침해나 구글 웹마스터 가이드라인 위반에 따른 수동 조치 사항이 없는지 확인합니다.

### 2. 네이버 서치어드바이저 점검 항목 (매월 1회)
* **목적**: 국내 점유율이 높은 네이버 포털의 웹페이지 수집 정합성 검수
* **체크리스트**:
  1. **[리포트 ➔ 수집 현황]**: 일별 수집 성공 및 실패 URL 개수를 파악하고 수집 오류 코드가 검출되는지 확인합니다.
  2. **[웹페이지 최적화] 점검**: 네이버 서치어드바이저 진단 툴을 통해 HTML 구조(Title, Description, Canonical, Robots)가 모두 **'최적'** 녹색 체크로 유지되고 있는지 진증합니다.
  3. **[사이트맵 제출]**: 사이트맵이 최신 상태로 잘 승인되어 작동 중인지 대조합니다.

## [OPS-102] 분기별 PageSpeed Insights 성능 점검

검색 순위 결정 요인이자 사용자 전환율에 지대한 영향을 미치는 코어 웹 바이탈(Core Web Vitals) 성능 점검입니다.

### 1. PageSpeed Insights 측정 요령
* **도구**: [Google PageSpeed Insights](https://pagespeed.web.dev/)
* **대상 주소**: `https://booboo.co.kr/` 및 8개 진료 서브페이지(`care-*.html`)
* **목표 점수**: 모바일 **80점 이상**, 데스크톱 **95점 이상**

### 2. 핵심 측정 지표 (Core Web Vitals)
* **LCP (Largest Contentful Paint - 최대 콘텐츠풀 페인트)**:
  - **기준**: **2.5초 이하** (우수)
  - **설명**: 첫 화면에서 가장 큰 이미지나 텍스트 블록이 렌더링될 때까지의 시간입니다.
* **INP (Interaction to Next Paint - 다음 페인트에 대한 상호작용)**:
  - **기준**: **200밀리초 이하** (우수)
  - **설명**: 사용자가 버튼 클릭 등의 상호작용을 한 후 브라우저가 화면을 실제로 업데이트하기까지 걸리는 반응 시간입니다.
* **CLS (Cumulative Layout Shift - 누적 레이아웃 이동)**:
  - **기준**: **0.1 이하** (우수)
  - **설명**: 로딩 과정에서 텍스트나 이미지가 예기치 않게 덜컥거리며 밀리는 비율을 의미합니다.

### 3. 정적 웹사이트 성능 유지/최적화 수칙 (운영자 가이드)
* **WebP 이미지 포맷 사용**: 새로 추가하는 병동 갤러리 이미지 등은 용량이 큰 JPG/PNG 대신 고압축 웹 이미지 포맷인 **WebP**(`*.webp`)로 포맷팅하여 업로드합니다.
* **이미지 지연 로딩 (`loading="lazy"`)**: 첫 화면(Hero) 이외의 하단 섹션 이미지에는 `<img loading="lazy">` 속성을 부여하여 스크롤 전 리소스 다운로드를 지연시킵니다.
* **CSS 및 JS 캐싱**: 서버(GitHub Pages) 배포 시 캐싱 헤더가 정상 활성화되어 작동하고 있는지 개발자 도구(F12 Network 탭)로 분기마다 확인합니다.

## [OPS-103] 분기별 구조화 데이터 정합성 점검

AI 답변 엔진(AEO)과 크롤러가 사이트 내부의 위치, 운영 정보, 비급여 수가 항목을 올바르고 입체적으로 인식하도록 동기화 상태를 정비하는 과정입니다.

### 1. 구조화 데이터 검증 도구
* **구글 리치 결과 테스트**: [Rich Results Test](https://search.google.com/test/rich-results)
* **스키마 마크업 검증 도구**: [Schema Markup Validator](https://validator.schema.org/)

### 2. 1:1 정보 정합성 교차 점검표 (분기별 1회 필수)
한의원의 실제 운영 조건이나 주소지가 변경될 때마다 다음 세 가지 공급원의 값이 **글자 하나 틀리지 않고 100% 동일**해야 합니다.

| 점수 대상 항목 | ① 웹사이트 HTML 표기 | ② JSON-LD 구조화 데이터 | ③ 로컬 플랫폼 등록 정보 (네이버/구글/카카오) |
|---|---|---|---|
| **대표 상호명** | 부부한의원 (목포 부부한의원) | `"name": "부부한의원"` | 부부한의원 (또는 목포 부부한의원) |
| **행정 도로명 주소** | 전남광주통합특별시 목포시 옥암로 193, 1~4층 | `"addressRegion": "전남광주통합특별시"`<br>`"streetAddress": "옥암로 193"` | 전남광주통합특별시 목포시 옥암로 193 (옥암동) |
| **대표 전화번호** | 061-272-1075 | `"telephone": "061-272-1075"` | 061-272-1075 |
| **평일 진료시간** | 09:00 - 20:00 (야간진료) | `"opens": "09:00"`, `"closes": "20:00"` | 09:00 - 20:00 (월~금 동일 표기) |
| **주말/공휴일 시간** | 08:30 - 14:00 (점심시간 없음) | `"opens": "08:30"`, `"closes": "14:00"` | 08:30 - 14:00 (토/일/공휴일 동일 표기) |

> [!IMPORTANT]
> 특히 진료 시간 개편이나 비급여 수가(예: 단순 추나, 약침 등 비용) 테이블 조정이 발생할 경우, 홈페이지 본문 텍스트 수정과 함께 `index.html` 하단에 있는 `<script type="application/ld+json">` 코드 블록 내의 스키마 속성값도 동시에 수정해 주어야 검색엔진이 모순이 없다고 판정하여 AEO 신뢰도 점수를 극대화할 수 있습니다.

## [OPS-105] 의료법 준수 의료광고 표현 정기 검수

국내 의료법 제56조(의료광고의 금지 등)에 근거하여 행정처분 및 포털 색인 제외 처분을 방지하기 위한 안전 장치입니다.

### 1. 마케팅 시 절대 금지되는 6대 표현 키워드
본문 텍스트를 임의로 수정하거나 새로운 소식을 등록할 때 아래의 과장·보장성 단어들은 보건소 심의 통과 없이는 **절대로 사용할 수 없습니다.**

1. **`완치`** (예: "디스크 완치 치료", "아토피 완치 보증") ➔ 치료 효과를 100% 확신하여 소비자를 현혹할 소지가 큼.
2. **`100%` / `전원`** (예: "치료 성공률 100%", "환자 전원 완쾌") ➔ 예외 없는 절대적 수치는 불법 광고로 규정됨.
3. **`보장`** (예: "치료 효과 보장", "재발 없는 치료 약속") ➔ 치료 행위는 결과가 아닌 수단이므로 예후를 사전에 약속할 수 없음.
4. **`부작용 없음` / `근손실 없음`** (예: "부작용이 전혀 없는 약침 치료", "근손실 없는 안전한 다이어트") ➔ 모든 의료 행위는 부작용 가능성이 수반되므로 오인의 소지가 있음.
5. **`최고` / `유일` / `최초`** (예: "목포 최고의 한의원", "전남 유일의 도침 치료") ➔ 공식적이고 객관적인 통계 입증서 없이 최상급 표현을 사용하는 것은 엄격히 제한됨.
6. **`즉시 효과` / `바로 개선`** (예: "추나 시술 즉시 통증 제거") ➔ 개인별 체질과 질환 정도에 따른 발현 속도가 다르므로 오인 가능성이 큼.

### 2. 환자 치료 후기 및 전후 사진 게재 수칙
* **비로그인 공개 제한**:
  - 치료 효과를 극적으로 보여주는 전후 사진이나 상세 환자 자필 치료 후기는 로그인(인증)을 한 회원만 열람할 수 있도록 제한 장치가 있어야 합니다.
  - 현재 부부한의원은 원페이지/서적 형태의 심의 완료 문구 위주로 구성되어 있으므로, **온라인상에 환자 후기를 무단으로 텍스트 복사하여 게재하지 않도록 합니다.**

### 3. 비급여 수가 고정 의무
* **기준**: 보건복지부 고시에 의거하여 환자가 비용을 쉽게 파악할 수 있도록 비급여 항목(어혈약침, 단순추나, 복잡추나 등)의 가격은 홈페이지 내에 명확히 명시되어야 합니다.
* **관리**: 가격이 인상되거나 인하될 경우, 실물 가격표 책자 개정과 홈페이지 비급여 모달 데이터의 일치성을 즉각 갱신해야 합니다.
