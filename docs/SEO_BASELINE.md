## 초기 확인 사항

- 홈페이지 본문은 검색 가능한 HTML 텍스트로 추출됨
- 진료 분야가 원페이지에 집중됨
- 진료·질환별 독립 URL이 확인되지 않음
- 표준 `robots.txt`, `sitemap.xml` 경로에서 404 확인
- 현재 HTTPS 제목과 과거 HTTP 검색 결과가 혼재함
- FAQ·질문형 구조·구조화 데이터는 추가 확인 필요
